✨ How this place works

Twenty-seven games and a studio. No account, no download, nothing to install — everything below lives in this browser.

🎮 Two kinds of game. The arcade plays in this page — a few minutes each. The flagships (Age of War, Startup Tycoon, Grow Op, Homeless Village, Voxel Isle, Hearthvale) are their own pages and run for hours; each opens with a crash course, and a ? button reopens it.
📅 The daily challenge. One shared seed a day: the same pieces, food and rocks for everybody who plays it. It is the one honest way to compare a score with someone else.
🏆 The Hall of Fame keeps your best in every game, and hands out trophies for milestones. Each trophy mints 🪙 coins, which buy accent palettes in the shop.
👥 Rivals, without a server. Share a code from the Hall of Fame and a friend's bests sit next to yours, lit up wherever they are ahead. Nothing is uploaded — the code is the data.
💾 It is all yours, locally. Saves, scores and trophies live in this browser and never leave it. ⬇ Backup in the Hall of Fame writes the lot to a file; ⬆ Restore puts it back on another machine.
📶 It works offline. Install it and the whole arcade — flagships included — keeps playing with no connection at all.
🎨 Make it yours. A 🎨 theme cycler and the coin shop's accents re-skin the site; press ? for every keyboard shortcut, and gamepads work throughout.

📰 Patch notes

What the studio shipped lately — every update is live for everyone, saves always migrate.

Google Tasks

Two-way sync with multiple Google Tasks lists. Your Work and Personal lists will show up as color-coded tags on each task. Requires a Google Cloud project with Tasks API + OAuth 2.0 credentials.

Connect Your Calendars

Add your Google Calendar API key and calendar IDs to see real events. Get an API key from the Google Cloud Console with Calendar API enabled. Your calendar ID is usually your email address.
